# AstroImageNow v1.12 — Rigs, forecast windows and site comparison

Baseline: v1.11.2, `eba6865f1023e8fafa7a54c1cc9413d39dd04c34`. Branch: `codex/multi-rig-opportunities`. September 19, 2026.

## What changes

**Plan targets** now selects a telescope, optical configuration, camera and imaging mode. The original Z73 plan IDs remain valid. C8 has exactly the three user-confirmed choices: native, f/6.3 reducer and Barlow; the latter selects the owned 2× or 3× X-Cel LX. UltraCat 56 uses its manufacturer-specified 269 mm, f/4.8 baseline. The camera selector offers the owned ASI533MC Pro and Canon R6 Mark II. Choosing an optical train calculates its sensor field and sampling scale; it does not certify adapter compatibility, commissioning or simultaneous availability of shared equipment.

The default camera for UltraCat is a **provisional shared ASI533 planning choice**, not a claim of a second/dedicated camera. C8 defaults to the existing Canon planning path and lunar/planetary mode. C8 alt-az field rotation and unverified camera/Barlow connections remain visible. Only the commissioned-inventory Z73/533 path offers L-Pro; other proposed trains start unfiltered until their filter path is confirmed.

Lunar/planetary mode computes topocentric positions of Moon, Venus, Mars, Jupiter and Saturn at every 10-minute sample, with Sun below −6°. It has no self-Moon penalty or Bortle penalty for bright planetary subjects. It does not predict disk size, video crops, opposition/transit events or solar observing. Deep-sky mode retains the 31-object catalog, darkness, Moon and framing rules.

Target windows now intersect altitude/night geometry with actual hourly astronomy and weather coverage. Missing hours are unknown, stale data cannot support a window, and no interval extends beyond the available samples. Rain/storm/fog/gust hazards block a matching interval; moderate hazards or Moon/dew cautions remain explicit. Planetary and long-focal-length seeing criteria differ from wide-field transparency criteria. The dashboard's legacy score remains a wide-field assessment, labeled separately.

**Same target, different site** compares the selected target/date/rig across saved locations. An explicit **Refresh site comparison** fetches the other sites, without changing the dashboard location. Each site uses its own coordinates, forecast and time zone. Provider choice and fallback behavior remain as configured. Comparison requests include two astronomy forecast calls and normal supplemental-weather calls per other site; no additional Moon API calls are needed. Up to ten site/source snapshots are kept locally, restored as stale. Credentials are never copied into that cache or saved plans.

## Next coherent increment: observing history and explainable recommendations

The user's intended product is a personal night-planning companion. The next layer needs evidence, not invented familiarity:

1. Add a device-local observing journal with stable target, site, rig/configuration, filter and session IDs; record date, captured exposure/integration, acceptance/quality notes, image references and user intent. Keep **unknown history**, **never captured**, **attempted**, **captured**, and **revisit for improvement** distinct. Import/reconcile known journal records before ranking from them.
2. Rank **selected-rig candidates** or propose an **overall mode/target/rig** using actual availability, geometry, forecast coverage, field fit, target class and journal goals. Explain the tradeoffs, especially seeing versus transparency and travel versus home convenience. Do not assume shared cameras/mounts can run twice simultaneously.
3. Add sourced time-sensitive opportunities: opposition/apparent size, lunar feature lighting, Jovian satellite/shadow events and selected transient/comet records. Store source, validity interval, retrieval time and uncertainty; expire stale event claims.
4. Reconcile UltraCat mount/camera/guide/filter configuration and C8 commissioning before representing those trains as ready for unattended use. Keep planning, packing/startup/shutdown procedures and device control separate.

No session history was invented or silently imported in this release. No new cloud synchronization, account connection, hardware command, calendar event, purchase or background automation was created.
